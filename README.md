# An AI Manifesto

*Intent is the new oil. Capping tokens is the leak.*

Brad Baker's five-year sovereign-AI roadmap: a scroll-driven essay with a fork at 2029 (own the boundary, or keep renting), an evidence ledger with every material claim tagged Verified / Brad's read / Prediction, and a Monday checklist.

| Folder | Edition | Status |
|---|---|---|
| `v3/` | **Broadsheet** — newsprint cream, serif, hand-drawn Sketchplanations-style artwork (V3.1.0) | current public edition |
| `v2-obsidian/` | **Obsidian** — dark Thermal Obsidian design system, native SVG figures (R4.3.1) | dark-mode / reference |
| `v4/` | **v4** — the talk edition: same thesis re-cut as a live presentation for AI people on the state of the market and how to sell up the chain for funding; figures rebuilt as interactive isometric machines (Anatomy) | in progress |

Each `index.html` is a single self-contained file: open it locally or serve it as-is (GitHub Pages, Vercel, Netlify). Fonts load from Google Fonts; everything else is inline. Both editions print as a leave-behind (every state final, both futures shown).

## Publishing with GitHub Pages

Settings → Pages → Deploy from branch `main`, folder `/ (root)`. The root `index.html` redirects to `v3/`.

## Versioning

- `v3.x` — Broadsheet (text frozen at R4.3.1 content; artwork V3.1).
- `v4.x` — the talk. Tracked in `v4/BRIEF.md`.

The decision record for the piece (every rule it obeys and the open questions) is the *intent file*, `docs/AI_Manifesto_intent.md`.
